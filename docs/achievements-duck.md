# Duck Pet: silly achievements

The silly achievement lines for Duck Pet, one pool per stage, plus a villain pool for a pet that hatched evil. Edit them here, then run `python -I tools/make_quips.py --duck`. The tool keeps the section names and the event labels below as they are, so change the lines, not the headings.

### Event lines (once each)
- **First meal of another duck:** ATE ANOTHER DUCKLING. THAT'S NOT VERY DUCKY.
- **Crowned in round one:** WON THE QUACK-OFF! THIS ONE IS YOURS.
- **Reaching stage 2:** GOT FLUFFY. MAXIMUM FLUFF ACHIEVED.
- **Reaching stage 3:** PIN FEATHERS! IT LOOKS LIKE A FEATHER DUSTER NOW.
- **Reaching stage 4:** REAL FEATHERS CAME IN. VERY SLEEK. VERY COOL.
- **Reaching stage 5:** ALL GROWN UP. A FULL-SIZE DUCK. HONK.
- **Your first bop of a rival:** YOU BOPPED A BAD DUCK. JUSTICE IS SERVED.
- **First time evolving is paused:** PAUSED. DUCK IN CRYO SLEEP.
- **100th meal:** 100 MEALS! DUCK HAS A FREQUENT EATER CARD.
- **Beat an evil duckling:** DEFEATED AN EVIL DUCKLING! THE POND IS SAFE.
- **First frog:** ATE ITS FIRST FROG. THE FROG HAD IT COMING.
- **First goldfish:** CAUGHT A GOLDFISH. THE GOLDFISH FORGOT TO SWIM.
